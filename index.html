03 — PROJECTS

Projects

01

Simulate Network Attacks and Defences Using Wireshark and Metasploit

This project focuses on network security and the analysis of common network attacks. It explores attacks such as Denial of Service (DoS) and SQL Injection and demonstrates how network traffic can be observed and analyzed. Wireshark is used for packet capture and traffic analysis, while Metasploit is used as part of the security testing process. The project provides practical exposure to identifying suspicious network activity, understanding attack patterns and studying defensive approaches in a controlled environment. It also helps in understanding how network monitoring and security testing tools can be used together to analyze potential vulnerabilities and improve awareness of network defence techniques.

Network Security · Wireshark · Metasploit
02

Fraud Analytics

This project focuses on fraud detection and prevention using machine learning and deep learning techniques. The objective is to analyze transaction-related data, identify patterns that may indicate suspicious activity and support the detection of potentially fraudulent behavior. The project explores how data-driven methods can be applied to fraud analytics and how predictive models can help organizations improve their approach to identifying unusual transactions and reducing fraudulent activity. It also provides an understanding of how machine learning approaches can support more reliable and efficient fraud analysis.

Machine Learning · Deep Learning · Fraud Detection
